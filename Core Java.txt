What is Exception Handling in Java?

Exception handling in Java is a mechanism used to handle runtime errors so that the normal flow of the program does not stop unexpectedly.
When an exception occurs, Java creates an exception object and transfers control to the appropriate exception handler.

public class Main {

        try {
            int a = 10;
            int b = 0;

            int result = a / b;

            System.out.println(result);

        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        }

        System.out.println("Program continues...");
    }

What are Generics in Java?

Ans: 


Generics in Java allow us to write classes, interfaces, and methods that can work with different data types.
The main purpose of Generics is to provide type safety and reduce the need for explicit type casting.
Instead of writing separate code for different data types, we can write one reusable class or method using Generics.



Example without Generics:

import java.util.ArrayList;

public class Main {

    public static void main(String[] args) {

        ArrayList list = new ArrayList();

        list.add("Java");
        list.add(100);

        String name = (String) list.get(0);

        System.out.println(name);
    }
}

Here, we can store different types of data in the same list.

But there are two problems:
We don't have proper type safety.
We need to perform explicit type casting.

Example with Generics:



import java.util.ArrayList;

public class Main {

    public static void main(String[] args) {

        ArrayList<String> list = new ArrayList<>();

        list.add("Java");
        list.add("Spring Boot");

        String name = list.get(0);

        System.out.println(name);
    }
}
Output: Java

Here, ArrayList<String> means we can store only String values.

If we try:

list.add(100);
Java gives a compile-time error.

Interview point: Generics provide compile-time type safety.

3. What is a Generic Class?
A generic class is a class that can work with different data types using a type parameter.

We generally use T to represent a type.

Example : 


class Box<T> {

    private T value;

    public void setValue(T value) {
        this.value = value;
    }

    public T getValue() {
        return value;
    }

public class Main {

        box2.setValue(100);

        System.out.println(box2.getValue());
    }
}
